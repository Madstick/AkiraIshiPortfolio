Connecting is an interactive living system that breathes with the Bitcoin blockchain. Each particle is an entity, each link a connection. When the network is congested the particles move faster, colours shift with transaction volume, and everything resets with every new block. The viewer can zoom with a lens, change and lock the font (only inscribed fonts are used) and set the activity by hand to see the different stages. There are two versions: the Ordinals one reads the time between blocks and how busy the network is, and a real-time version reacts directly to the chain.Connecting est un système vivant interactif qui respire au rythme de la blockchain Bitcoin. Chaque particule est une entité, chaque lien une connexion. Quand le réseau est congestionné, les particules accélèrent, les couleurs changent avec le volume de transactions, et tout se réinitialise à chaque nouveau bloc. Le spectateur peut zoomer avec une loupe, changer et verrouiller la police (seules des polices inscrites sont utilisées) et régler l'activité à la main pour voir les différents états. Il existe deux versions : celle des Ordinals lit le temps entre les blocs et l'activité du réseau, et une version en temps réel réagit directement à la chaîne.
